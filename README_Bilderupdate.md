# ITOGO – Rezeptbilder direkt integriert

Die 26 KI-erstellten Rezeptbilder sind vollständig in `index.html` eingebettet.
Ein separater Bilderordner ist nicht erforderlich.

## Bestehende App in GitHub aktualisieren

1. Die neue `index.html` herunterladen und im bisherigen App-Ordner die vorhandene `index.html` ersetzen.
2. Ebenso die neue `sw.js` herunterladen und die vorhandene `sw.js` im selben Ordner ersetzen.
3. Die Änderungen speichern (Commit changes) und die Veröffentlichung abwarten.
4. Die App schließen und erneut öffnen. Gegebenenfalls die Seite einmal neu laden.

Die Dateien müssen genau `index.html` und `sw.js` heißen. Die ZIP enthält außerdem die übrigen ursprünglichen App-Dateien für ein vollständiges Paket.

Die vorhandenen 203 Rezepte, Nährwertangaben und Anleitungen bleiben erhalten. Die 26 passenden Rezeptkacheln verwenden die integrierten Bilder; eigene Rezeptfotos haben weiterhin Vorrang. Der übrige App-Stil wurde nicht geändert.

Die Bilder sind KI-generierte Illustrationen der Gerichte. Sie sind keine Dokumentation einer tatsächlich zubereiteten Portion.
